# 04 — Create a Deal Room and join as buyer

**What to build:** A seller creates a Deal Room for one listed account
and gets a link. Another trader opens the link, sees the terms, and
joins as the buyer.

**Blocked by:** 03

**Status:** todo

- [ ] New Deal asks for title, description and price in pesos, with a
      warning never to put login details in the description
- [ ] The `deals` table exists with the columns in the spec, Row Level
      Security on, and its policies: only the seller and buyer may read;
      a logged-in trader may create only as the seller; nobody may
      update or delete directly
- [ ] An ownership code is generated by the database when a deal is
      created
- [ ] Creating a deal opens its Deal Room, showing the link to send
- [ ] The deal preview function shows title, description, price and
      seller to a logged-in trader with the link, and never shows the
      ownership code
- [ ] The join function makes the caller the buyer only if the deal has
      no buyer and the caller is not the seller
- [ ] Your own Profile lists every Deal Room you are in, with its step,
      and has a New Deal button
- [ ] A third trader who isn't in the deal can't read it
- [ ] Every database change is saved as a numbered SQL file
- [ ] Works on the live URL
